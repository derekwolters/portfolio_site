# Meridity Portfolio Site

## Available Scripts

In the project directory, you can run:

### npm run dev

Starts the Vite development server.

### npm start

Alias for npm run dev.

### npm run build

Builds the app for production using Vite.

### npm run preview

Serves the production build locally.

### npm test

Runs the test suite once with Vitest.

### npm run test:watch

Runs Vitest in watch mode.

### npm run typecheck

Runs TypeScript checks without emitting files.
