# Meridity Portfolio Site

A static site built with [Eleventy](https://www.11ty.dev/). Projects shown on the
homepage are data-driven from `src/_data/projects.json` — add an entry there
(with an `image` path pointing into `src/images/`) and it appears on the site
after the next build.

## Available Scripts

In the project directory, you can run:

### npm run dev

Starts the Eleventy dev server with live reload.

### npm start

Alias for npm run dev.

### npm run build

Builds the static site into `_site/`.
